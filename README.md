🖼️ AI Image Resizer

A lightweight and interactive AI Image Resizer built using Python, OpenCV, and Gradio.
This tool allows users to resize images using fixed dimensions or scale factors with multiple interpolation methods, focusing on speed, accuracy, and simplicity—without model training or epochs.

📌 Features

✅ Resize images using custom width & height

✅ Resize images using scale factor

✅ Multiple interpolation methods:

Nearest

Linear

Cubic

Lanczos

✅ Interactive Gradio Web UI

✅ Fast image processing (No ML training)

✅ Works on Windows / Linux / macOS

🛠️ Tech Stack

Python 3.8+

OpenCV

NumPy

Pillow

Gradio
